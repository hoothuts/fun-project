## Wikimedia download facts (learned the hard way)
- Search API: `en.wikipedia.org/w/api.php?action=query&list=search&srsearch=<name> circuit&srnamespace=6&srlimit=12` → pick top `.svg`
- Download: `https://commons.wikimedia.org/wiki/Special:Redirect/file/File:<url-encoded title>` with UA header `F1GridArchive/0.2 (personal hobby project)`
- **Commons 429s intermittently, per-Varnish-backend** — random routing means some requests always succeed; patient retries (15/45/90/180s) break through eventually. `upload.wikimedia.org` is hard-blocked (every request 429s).
- **webfetch (opencode server infra, different IP) bypasses the block entirely** — proven for Monaco, Detroit (237KB, saved to tool-output file, copied to disk), AVUS. Use as fallback for stubborn files.
- 404 ≠ 429: 404 means the file TITLE is wrong (throttle clear), 429 means keep retrying.
